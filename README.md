# SprintHub VoIP

Aplicativo para desktop para realizar e receber ligações pelo SprintHub

> Atenção: Apenas usuários do SprintHub conseguiram fazer o uso deste aplicativo para realizar e receber ligações.

## Login

Para entrar no aplicativo é preciso se autenticar através da tela de login. Entre com o subdomínio da sua instância e em seguida com as credenciais de acesso. Como mostrado na imagem abaixo:

![login](https://i.ibb.co/ksyKfXjF/Captura-de-Tela-2025-11-17-a-s-08-37-52.png)

## Menu

Depois de logado escolha quais ações deseja tomar dentro do aplicativo. Você tem opções como Discador, visualizar os contatos, ver o histórico de ligações e demais como configurações e ajustes:

![menuu](https://i.ibb.co/LdWWTZ28/Captura-de-Tela-2025-11-17-a-s-08-41-26.png)

## Baixar e Instalar

Siga os passos abaixo para fazer o download do Aplicativo e instalar em seu computador de acordo com o sistema operacional:

### Windows

1. Faça o download:
[Download Windows](https://google.com/)
2. Execute o instalador
3. Caso apareça a janela de proteção, clique em "Mais informações" e coloque para executar:
![protect](https://i.ibb.co/hRCscKB6/unnamed.png)
4. Abra o aplicativo

### MacOS

1. Faça o download:
[Download MacOS](https://google.com/)
2. Execute o instalador
3. Caso apareça uma janela de permissão do MacOS, vá em configurações e permita "Desenvolvedores Desconhecidos":
![macosprotectother](https://i.ibb.co/GQkZNfb2/Captura-de-Tela-2025-11-17-a-s-09-09-59.png)
4. Abra o aplicativo

### Linux (debian, )

1. Faça o download:
[Download Linux](https://google.com/)
2. Extraia os arquivos
3. Abra o aplicativo
